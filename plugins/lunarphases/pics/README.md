# KOrganizer moon phase icons

## Origin Story

The original set of 4 moon phase icons were created in October 2021
by Friedrich W. H. Kossebau <kossebau@kde.org> and were based
on the breeze icon wether-clear-night.svg. Only the new, full,
first and last quarter phases were included.

## All the phases

In August 2026, Allen Winter <winter@kde.org>, wanting to support all the
moon phases, copied in Daniel Kmiec's freely available (CC BY 3.0 license)
icons from <https://en.wikipedia.org/wiki/Lunar_phase>. Although
we now had the complete set of phases, these black/white icons
didn't work for dark-mode and were generally not very exciting.

## Better color

In October 2026, Allen made added translucency and re-colored all the icons
(from black to gold) with the goal of finding a color that looks good in
both light- and dark-modes.

This was done using the ImageMagick tool, by-hand, one-by-one.

The copyright does not change simply due to the new color.

## Summary

The gold looks good enough in both light- and dark-modes; however,
we are open to improvements if anyone wants to donate better icons
for all the phases and look good in different darkness modes.
